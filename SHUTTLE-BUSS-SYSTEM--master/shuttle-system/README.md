# Shuttle Bus MUT — HTML Prototype

## สิ่งที่อัปเดตล่าสุด
- **Login หน้าเดียว** ไม่แยกพนักงาน/ผู้ใช้ — ระบบตรวจเอง
- **สมัครสมาชิก** (`register.html`) สำหรับผู้ใช้บริการ
- **ผู้ใช้บริการ + คนขับ** ออกแบบ UX มือถือ (bottom nav, การ์ด, ปุ่มใหญ่)
- **จำนวนที่นั่งตอนจอง** จำกัดตามที่ว่างจริง (และไม่เกิน 4)
- **Admin CRUD** พนักงาน/ตำแหน่ง/สิทธิ์, รถ, เส้นทาง, รอบรถ, รายงาน

## วิธีเข้า
